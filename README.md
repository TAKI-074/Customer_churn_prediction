Customer Churn Prediction API

## Overview
This project builds and deploys a Machine Learning model to predict customer churn using a Random Forest classifier.  
The trained model is exposed as a REST API using FastAPI, enabling real-time churn predictions via JSON requests.

This project demonstrates an end-to-end ML workflow:
- Data preprocessing
- Model training and evaluation
- Model serialization
- API deployment for inference

## Problem Statement
Customer churn prediction helps businesses identify customers likely to leave their service.  
By predicting churn in advance, companies can take proactive retention actions.

- Scikit-learn
- FastAPI
- Uvicorn
- NumPy
